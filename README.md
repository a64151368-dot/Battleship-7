# Морський бій — фізика, 8 клас

- `index.html` — гра. Відкрийте у браузері.
- `instrukciya.html` — інструкція для вчителя.
- `assets/` — зображення. Папка має лежати поруч з обома файлами.

Для GitHub Pages завантажте вміст цієї папки в корінь репозиторію й увімкніть Pages у Settings → Pages.
Шрифти беруться з Google Fonts, тому потрібен інтернет.
